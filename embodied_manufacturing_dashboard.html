主线 A · 首期优先

小批量柔性装配与恢复

首期用宽容差或带导向件；精密插装要具备可验证的接触控制能力。

主线 B · 双臂有明确价值时

主动持件与协同装配

双臂夹爪非对称支撑 / 交接

一臂持壳体/支架，另一臂插接；也可通过交接改变抓取姿态。与单臂加固定夹具比较柔性、恢复和节拍。

重点对照：、、。

主线 C · 工站能力提升

工具使用 + 长程质量闭环

持件 / 持工具6–10 个业务步骤

来料配套 → 插装 → 取工具 → 紧固 → 验收 → 装盒。研究工具选择、工序依赖、执行监控与返修。

建议的核心问题：在未知工件批次、位姿偏差与可恢复失败下，分层规划 + 学习接触技能 + 独立质量检测，能否比脚本基线和端到端视觉策略完成更多合格装配，并减少人工介入？该假设可通过受控实验验证。

从赛事任务到制造工站

面向制造的生成流水线

本报告提出的实现方案：先验证小规模真实工件，再决定是否扩增。

1. 工件与工艺CAD / STL、容差、材料、质量判据、可抓区域
2. 场景与本体URDF、夹爪、料盒、夹具、相机与工具 TCP
3. 合法工序前置条件、资源互斥、持件角色、可恢复状态
4. 示范与扩增自采成功/失败/恢复；对象扰动与专家合成
5. 质量与隔离独立验收、重复去除、几何/批次隔离、实机检验
制造生成器的边界：“物体不穿透 + 目标谓词成立”只证明有限仿真条件。工具柄是否夹得稳、螺纹是否真实啮合、线缆是否有张力、工件是否损伤，需要额外建模与实物测量。生成测试集不能与训练源示范共享同一批几何或目标序列。

值得写成论文的三个问题

  1. 泛化：未见几何/批次与目标组合下，CAD 或语义先验能否减少新示范量？
  2. 恢复：视觉 + 力/状态的阶段检测，是否比只靠图像判断减少卡滞和损伤？
  3. 协同：双臂主动持件在换型和失败恢复上，是否优于同预算单臂 + 固定夹具？

必须放在一起比较的基线

① 状态机 + 几何视觉 + 运动规划；② ACT；③ Diffusion Policy；④ 同类可开放复现 VLA 微调；⑤ 工序规划 + 接触技能 + 质量监控。

开放模型具体版本按实验启动时可用权重选择，并记录训练数据。共享示范预算、观测条件、控制频率、重试次数和算力；消融只改变一个因素。

按验收条件推进的实施路线

时间为 2–3 名参与者、硬件及时到位的工程估计，不是已承诺排期；依阶段验收决定扩展。

阶段 0 · 约 1–2 周

接口与标定

可重复运动、夹爪、URDF、相机、同步、日志；录制并回放完整 episode。

退出条件：连续 20 次基础抓放，记录失败与误差，不只挑成功视频。

阶段 1 · 约 2–4 周

三个原子技能

T01 抓放、T03 导向插装、T04 交接（有双臂时）；建立脚本和 IL 基线。

退出条件：形成质量判据、独立初态集与可重复结果。

阶段 2 · 约 4–6 周

工序链与恢复

4–6 步组件组装，加入错姿态、缺料与卡滞；比较规划和恢复模块。

退出条件：报全链合格率、失败阶段、介入与耗时。

阶段 3 · 按资源扩展

工具 / 未见工件

加入 T07、T10 或 T12；扩增生成数据并验证收益，开放小型制造任务包。

退出条件：测试几何/工序与训练隔离；真实质量指标支持结论。

硬件路线：URDF 是起点，控制适配是关键

参考用户给出的 PiperX、宇树 R1-7A、越疆 CR5；规格与接口以最终实际型号/固件核对，不假设原生腕部六维力。

PiperX 类六轴科研臂

官方提供 Python/C++、ROS/ROS2 与 CAN 接口方向。适合起步采集、仿真适配和双臂夹爪实验。

核对 PiperX 对应协议/固件及驱动支持；位置、速度、力矩接口的可用性、延迟与反馈精度实测。

相机按信息需求逐级加

选型前先实测场景遮挡、距离、反光、同步与推理速度；多相机不是默认更好。

配置合适任务新增信息 / 成本建议的对照
1 视角：固定全局 RGB / RGB-D分拣、配料、规则工件上下料覆盖全场；夹爪和工件遮挡孔口，单目几何不确定固定照明起步；对比俯视与斜侧视，相机型号/内参锁定
2 视角：全局 + 操作腕部单臂定向插装、工具对准近距离几何；增加手眼标定、时间同步、腕部载荷同样示范预算对比单视角；区分可见性提升与数据量提升
3 视角：全局 + 左/右腕部双臂主动持件、交接、柔性件两臂局部接触信息；自遮挡、带宽和模型输入成本全局单视角 / 全局+操作腕 / 三视角，逐一消融
力/力矩与工艺传感紧配合插装、螺纹、卡扣、紧固验收腕部力、工具扭矩、深度/连通测量；独立校准RGB-only / RGB+本体 / RGB+有效接触信号，不用未标定电流代替质量标签
最小硬件组合：机械臂 + 平行夹爪 + 固定相机 + 可重复定位夹具 + 软指尖 + 基础工件即可启动抓放与宽容差装配。精密插装建议增加腕部近视角和有效接触反馈；工具紧固增加可读的工艺结束/扭矩信号。各任务都保留急停、限位与受控执行条件。

更换 URDF 还需同步更换什么

  • 关节顺序、范围、方向、单位、质量/惯量与碰撞几何。
  • 夹爪开度/力范围、指尖接触、末端 TCP 与工具 TCP。
  • 动作语义：绝对/增量、关节/笛卡尔、基座/工具坐标系。
  • 控制频率、队列延迟、插值、驱动增益、速度与加速度限制。
  • 相机内外参、双臂外参、时间同步与成功判据。

采集一条 episode 的最小记录

episode_id / task_id / object_geometry_id / batch_id
robot_and_gripper_version / calibration_id
timestamps / RGB[D] / joint_states / EE_pose
commanded_action / executed_action / gripper_state
force_torque_if_available / stage / event
quality_result / failure_type / recovery / intervention

保留成功、失败、中途介入与恢复。记录命令与执行反馈的时序差距；多视角独立时间戳对齐。人体视频、SLAM 位姿和关节控制字段要分清来源。

评测什么，才能回答制造问题

“走到目标位姿”与“产出合格件”分别记录，重试和人工介入都计入结果。

指标定义 / 报告方式为何需要
全链合格率完整订单所有必要工序完成，且独立质量检测通过的 episode / 全部启动 episode防止用单步成功率夸大长程能力
原子成功 / 阶段质量独立初始化原子技能成功率；在真实工序链中逐阶段成功/失败分布另报独立原子分数不等于条件阶段分数，能定位早期失败
几何 / 工艺质量插入深度、装配间隙、转动/连通测试、目标扭矩、拉脱或张力；按任务选择避免图像“看着装上了”而实际不合格
节拍与吞吐含推理、控制、重试、质量检查的墙钟时间中位数/P90；合格件/小时搬运与双臂并行是否改善制造效率
恢复与介入可控注入失败后的恢复成功率、恢复耗时；每订单介入数、重试数与放弃数稳定性与故障闭环是真实工站的重要能力
接触与损伤具备有效测量时的峰值力/超阈值次数；独立检查损伤/滑牙/线缆异常评估接触策略质量，阈值按工件与测量标定设置
泛化与数据效率ID、未见工件几何、未见批次、未见工序组合、相机/照明变化分别统计；示范量学习曲线避免混合多个变量后无法解释失败原因

统计与划分建议

开发阶段每任务约 20–30 次可发现大故障；最终比较建议每任务至少 50 次独立初态评测，报告成功/总数与 95% Wilson 区间。有训练随机性时使用至少 3 个训练种子；真机预算不足时明确区间与限制。

以上是实验设计建议，不是所有 benchmark 的官方统一协议。不同资源需保留其官方试验次数、时限与扰动设置；仅在相同协议内比较分数。

公平对比与泄漏控制

固定观察模态、动作频率、质量阈值、时间预算、最多重试、人工介入规则与示范预算。按工件几何/批次/工序组合划分，不能把同一条长轨迹的相邻片段分到训练和测试。

若每步成功率假设独立且为 95%，10 步全链约为 0.95¹⁰ ≈ 60%。真实阶段失败有关联，此值只用于说明误差累积，不是实测预测。

维度定义 · 本报告分类

A1：自由空间抓放、低接触搬运。A2：姿态调整、重抓、低约束工具/柔性操作。A3：高约束接触、精密插入、螺纹、啮合或强耦合柔性操作。类别是任务族覆盖，不是同一数值量表。

原子/短程指单技能或少量子步骤；长程指有多阶段依赖、记忆或连续任务链。不用控制 timestep 数作为业务步骤数。人体与纯零件轨迹的机器人接触难度为“不适用”。
